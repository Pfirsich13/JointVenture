Seite öffnen
So installierst du das Admin-Programm auf deinem PC
  1. Öffne diese Seite in Microsoft Edge oder Google Chrome (Opera und Firefox können das nicht).
  2. Edge: oben rechts auf „…“ → Apps → Diese Website als App installieren → Installieren.
    Chrome: rechts in der Adressleiste auf das Symbol mit dem Bildschirm und Pfeil → Installieren.
  3. Danach gibt es „JointVenture Admin“ im Startmenü. Rechtsklick auf das Symbol in der Taskleiste → An Taskleiste anheften.
